# hfx — the HuggingFace free-maxxing kit

**Consumer onboarding: read `AGENTS.md` first.** One CLI (`bin/hfx`) for every
verified-free HuggingFace capability: status · store · cdn · host · infer ·
gpu · mcp · etl · oauth · registry · token · watch · social · md · monitor.

```bash
bin/hfx status          # verify your setup in 10 seconds
```

This kit is the distilled, tested output of the hf-free-maxxing research
project (Sep 2026 live-verification; findings/ + playbooks/ in the research
repo). Start with the skill's `SKILL.md` (one directory up), then `AGENTS.md`
below — both written for CONSUMERS.
